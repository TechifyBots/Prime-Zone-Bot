## 🌸 Overview

**Prime Zone Bot** is a feature-rich **Telegram bot** that combines **video processing, free and premium access, and subscription management** in one place. With configurable usage limits and automated subscription tracking, it offers a flexible experience for both users and administrators.

> *💡 Your Videos. Your Zone. Your Prime.*

#### 🤔 Why Choose This Project?

- 🎬 **Flexible Video Access** — Support free and premium video processing.
- 💎 **Premium Benefits** — Offer subscription plans with enhanced access.
- 📊 **Usage Control** — Manage daily limits and video duration restrictions.
- ⚙️ **Easy Management** — Handle users, subscriptions, and bot settings.

#### 🔄 How It Works

1. 📩 **Start the Bot** — Open the bot and explore its available options.
2. 🎬 **Send a Video** — Submit content for processing.
3. 💎 **Access Premium** — Upgrade your plan for additional benefits.
4. 📊 **Track Your Usage** — Check your remaining limits and subscription status.

---

## ✨ Features

- 🔒 **Access Control** — Manage content access with free and premium user limits.
- 🆓 **Free Access** — Use the bot with configurable daily usage limits.
- 💎 **Premium Membership** — Unlock additional access with a premium subscription.
- ⏱️ **Duration Restrictions** — Apply video duration limits for free users.
- 📅 **Subscription Plans** — Support weekly, fortnightly, and monthly plans.
- 📊 **Usage Tracking** — Monitor daily usage and remaining limits.
- 🔄 **Auto Expiry Management** — Automatically manage expired premium subscriptions.
- 👥 **User Management** — Ban, unban, and manage users.
- 📢 **Broadcast System** — Send announcements to bot users.
- ⚙️ **Admin Controls** — Manage subscriptions, usage limits, and bot maintenance.
- 🚀 **Multi-Platform Deployment** — Deploy easily on Koyeb, Heroku, Railway, and Render.

## 📝 Configuration

| Variable | Description |
|:---------|:------------|
| `API_ID` | Telegram API ID |
| `API_HASH` | Telegram API Hash |
| `BOT_TOKEN` | Telegram Bot Token |
| `MONGO_URI` | MongoDB URI |
| `ADMIN_ID` | Telegram User ID |
| `PICS` | Start Images |
| `FREE_VIDEO_DURATION` | Your free content time in seconds |
| `IS_FSUB` | Enable / Disable Force Subscribe |
| `FSUB_EXPIRE` | Force Subscribe Expire Time |
| `AUTH_CHANNELS` | Force Subscribe Channels |
| `AUTH_REQ_CHANNELS` | Request FSUB Channels |
| `LOG_CHANNEL` | Log Channel |
| `VERSION` | Bot Version |
| `DATABASE_CHANNEL_ID` | Database channel ID for bot to store content |
| `DATABASE_CHANNEL_LOG` | Channel ID for Database logs |
| `PING_URL` | Service URL for Keep-alive |
| `SOURCE_CODE` | GitHub repository URL |

## 🤖 Commands

```
start - Check Bot Alive.
help - Bot usage guide.
myplan - Check your current plan.
stats - View bot statistics.
broadcast - Send message to all users
ban - Ban a user from using the bot
unban - Unban a previously banned user
banlist - To Check banned Users
maintenance - Toggle maintenance mode
prime - Add premium access for a user
remove - Remove premium access from a user
setlimit - Set daily limits for free/premium users.
getvideos - To get your recommended videos/files.
deleteall - Delete all videos from database
delete - Delete specific video by ID.
```
